# Codex 연결 구성

이 저장소는 루트 `AGENTS.md`를 자동 탐색 진입점으로 사용한다.
실제 연결 규칙은 [CODEX.md](../CODEX.md), 공통 절차는 [CLAUDE.md](../CLAUDE.md)에 있다.

이 폴더는 Codex 연결 안내를 보관한다.
현재 연결에는 `config.toml`이 필요하지 않으며 모델, 권한, 신뢰 설정을 강제하지 않는다.
`.claude` 설정을 이 폴더에 복사해도 hook과 슬래시 명령이 이식되는 것은 아니다.
소비 프로젝트에 설치하는 방법과 읽기 전용 확인 절차는 `CODEX.md`를 따른다.

## 요약

- 자동 탐색은 루트 `AGENTS.md`, 공통 규칙 재사용은 `CODEX.md`가 담당한다.
